# LEXORA — SUPPORT AND PRIVACY CENTER

Create two connected account pages using the existing Lexora application shell.

## Support Page

Display:
- Support page title.
- Create ticket button.
- Ticket ID.
- Category.
- Ticket status.
- Last update.

Ticket detail page:
- Chronological conversation.
- Message composer.
- Current status.
- Ticket reference.

Supported statuses:
- OPEN
- IN_PROGRESS
- WAITING_FOR_USER
- RESOLVED
- CLOSED

Allow resolved tickets to be reopened within seven calendar days.

Do not include file attachment upload functionality in the MVP.

## Privacy Center

Display:
- Consent preferences.
- Consent purpose and version.
- Data export request.
- Data deletion request.
- Access request.
- Correction request.
- Objection request.
- Request status and timeline.
- Processor and retention information.

Use understandable language and avoid presenting the entire privacy policy as a wall of text.

Keep privacy controls easy to find and understand.
