# LEXORA — AI HUMANIZER EDITOR

Create a professional text editing workspace for Lexora.

Use a two-pane editor layout.

### Top Toolbar

- Page title: AI Humanizer.
- Built-in writing style dropdown.
- Personal style profile dropdown.
- Character counter.
- Credit estimate.
- Primary action: "Humanize".

### Built-in Styles

- Academic
- Formal
- Professional
- Casual
- Informative
- Creative

### Main Editor

Left panel:
- Title: "Teks Asli"
- Editable source text.
- Character count.
- Upload document action.

Right panel:
- Title: "Hasil Humanizer"
- Generated result.
- Copy action.
- Download action.

Keep both panels visually balanced.

The original text must remain unchanged by the generation process.

### Bottom Toolbar

- Compare changes.
- Copy result.
- Download.
- Save to history.

### Warning

"Periksa kembali fakta, angka, kutipan, dan makna sebelum menggunakan hasil."

### Character Limits

Minimum: 100 extended grapheme clusters.

Maximum: 50,000 extended grapheme clusters.

### Mobile

Switch to stacked panels or tabs:
- Teks Asli
- Hasil Humanizer

Keep the primary action accessible without covering the editor.

Do not display fake quality scores or claims that the output is undetectable.
