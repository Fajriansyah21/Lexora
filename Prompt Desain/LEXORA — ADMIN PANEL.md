# LEXORA — ADMIN PANEL

Create a separate operational Admin Panel for Lexora.

Use a professional, restrained interface optimized for operational work.

### Sidebar Navigation

- Overview
- Users
- Jobs
- Payments
- Credit Ledger
- Support
- Provider Configuration
- Sensitive Access Requests
- Audit Logs
- Operations
- Roles & Permissions

### Overview

Show operational summaries only when real data is available.

### Data Tables

Use:
- Search.
- Filters.
- Pagination.
- Status labels.
- Clear table hierarchy.
- Explicit action menus.

### Security Requirements

Never show raw user text in default tables, previews, or analytics.

Sensitive text access must require:
- Explicit user consent.
- Valid support ticket.
- Authorized role.
- Narrowly scoped access.
- Maximum one-hour expiry.

Every privileged action requires a reason and creates an audit record.

Distinguish:
- Super Admin.
- Admin.
- Moderator.

Use clear confirmation dialogs for destructive and privileged actions.

Do not make the Admin Panel visually identical to the user dashboard. It should be more operational and information-dense.
